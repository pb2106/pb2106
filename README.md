Inventor on two patents — **WRU**, a kernel-level USB security framework enforcing network-layer monitoring and device access control, and **TORUS**, a minimal-knowledge ECC authentication system built around a rotating, non-transmitted secret. I like building the working version of a security control, not just the writeup of one.
